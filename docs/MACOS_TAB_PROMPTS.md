# macOS Tab UI Prompts

These prompts were rebuilt from the current macOS shell structure and destination lists.
They are written to help update the UI for each tab without drifting back toward an iPhone-style layout.

## 1. TimeBite Overview Prompt

Use this when updating the `TimeBite > Now` tab.

Prompt:

> Rework the macOS `Now` tab so it feels like a workspace dashboard, not a mobile summary screen. Keep the layout spacious and desktop-native, with a strong first-read hierarchy for current priority, next action, and progress. Reserve clear regions for the live activity ring, today's focus, and short AM/PM summary cards. Make the page feel useful even with placeholder data, and avoid cramped card grids or phone-style navigation patterns.

## 2. Actions Prompt

Use this when updating the `TimeBite > Actions` tab.

Prompt:

> Design the `Actions` tab as an execution surface for the day. Show a clear list or queue of actionable items with obvious status, urgency, and completion affordances. The macOS layout should support scanning, keyboard-driven interaction, and a strong primary action area. Keep the surface calm, structured, and information-dense, while avoiding a stretched mobile list or overly decorative dashboard treatment.

## 3. Goals Prompt

Use this when updating the `TimeBite > Goals` tab.

Prompt:

> Turn the `Goals` tab into a long-lived planning view that highlights hierarchy, progress, and relationships between goals. The layout should favor a sidebar-and-detail or master-detail feel, with room for goal state, current objective, linked actions, and progress context. Keep the desktop presentation crisp and editorial, and make it easy to understand which goal matters most right now.

## 4. Plan Prompt

Use this when updating the `TimeBite > Plan` tab.

Prompt:

> Rebuild the `Plan` tab as a macOS planning workspace with strong structure and generous spacing. The interface should support planning hierarchy, calendar or timeline context, and clear editing affordances without feeling like a copied iPad layout. Emphasize the plan tree, active focus, and upcoming blocks, and keep placeholder sections aligned so the final data model can land later without another layout rewrite.

## 5. Track / Dashboard Prompt

Use this when updating the `TimeBite > Track` and `TimeBite > Dashboard` tabs.

Prompt:

> Design the `Track` and `Dashboard` tabs as analytical surfaces with clear visual hierarchy and desktop-native density. `Track` should focus on trends, streaks, and time-based review, while `Dashboard` should summarize the current state at a glance with a few high-signal metrics. Keep the layouts balanced, avoid tiny mobile chart patterns, and make sure the visuals feel intentional even when the underlying data is still partially mocked.

## 6. Creating Your Reality Prompt

Use this when updating the `Creating Your Reality` space tabs: `Create`, `Discover`, `Journal`, `Library`, and `Me`.

Prompt:

> Rework the `Creating Your Reality` space so it feels clearly distinct from TimeBite: more reflective, exploratory, and creative, with a softer emotional tone and a calmer visual rhythm. Each tab should feel like a dedicated workspace, not a generic feature bucket. `Create` should foreground a starting point for making something new, `Discover` should support browsing and collecting inspiration, `Journal` should feel private and low-friction, `Library` should organize saved material with strong hierarchy, and `Me` should surface identity, preferences, and personal context. Keep the layout spacious, macOS-native, and cohesive across the whole space, while avoiding mirrored TimeBite patterns, dense mobile lists, or overly literal productivity chrome.

## Suggested Usage

- Use the prompts above as the base instruction when generating or revising each tab.
- Keep the shell, navigation, and spacing patterns consistent across tabs.
- Let the content and layout language differ by tab so each surface has a clear job.
